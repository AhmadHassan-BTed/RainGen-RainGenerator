Sound in space

Every drop has a place.

Rain lands all around you. Wind arrives from its bearing. Thunder reaches you after the flash, at the speed of sound in that air.

  1. Around the listener 3DEvery impact, gust and thunderclap is placed in the scene and heard from where you stand.
  2. Stereo 2.0Two speakers at ±30°, folded down from the full scene.
  3. Surround 5.1Rain all around, thunder from its bearing, low end on the LFE, with the right WAVE channel masks.
  4. Immersive 7.1.4Four height channels put the rain overhead. Binaural for headphones, and AmbiX ambisonics, first to third order, for 360 video, VR and game engines.

Physics, not loops

Rain is a population of drops.

raingen simulates the drops, the surfaces they strike, the wind in trees and wires, and the air the thunder crosses to reach you. Nothing is a recording, so nothing repeats.

For your work

Wherever weather has to sound real.

  • Film and TV

    Stems, BWF with timecode and the scene in iXML, 7.1.4 and ambisonics, UCS names, and EDL cue sheets for every thunderclap and gust.

  • Games

    Parameters in human units, a real-time engine with smooth glides, Wwise and FMOD manifests, and a seed per scene so QA can reproduce any bug.

  • Music

    Thunder one-shot packs with UCS names, stems that mix like any other track, and OSC control of the live engine.

  • Sleep and focus

    Relax, Sleep and Focus modes with low default levels, a timer and a long fade-out. No sudden loud sounds, and no loop for your ear to learn.

  • Apps and installations

    A browser engine on Web Audio, a Python library and CLI, and one open scene format between them. METAR, disdrometer and live-weather import.

Developers

Plain words in.
Sound out.

A Python library, a CLI and a browser engine that share one scene format. Every example runs as shown.

import raingen as rg

# 1 · Just listen (real time; Ctrl+C stops; needs the "audio" extra)
rg.play("rain on a tent, gusty, distant thunder")

# 2 · Plain words → file (streams to disk; any length)
report = rg.render("rain on a tin roof, wind 30 km/h from the west, distant thunder",
                   minutes=60, out="cabin_storm.wav", destination="youtube")
print(report)   # the file, loudness, true peak, events and the words it understood

# 3 · Human units, one canonical path per parameter
scene = rg.preset("tent-in-a-storm")
scene.weather.precipitation.rate_mm_h = 8
scene.weather.wind.speed_mps = rg.beaufort(5)      # 9.3 m/s, "fresh breeze"
scene.weather.wind.from_deg = 270                  # meteorological "from": the west
scene.weather.thunder.distance_km = 3              # ≈ 8.7 s flash-to-bang at 20 °C
print(scene.describe())                            # "What am I hearing?" in plain words
scene.save("my_tent.json")                         # the whole storm in about 2 KB

# 4 · Long renders stream to disk in bounded memory
scene.render(hours=10, seed=42, out="tent_sleep.wav", destination="sleep", mode="sleep")

# 5 · Studio: automation, stems, 7.1.4, cue sheets, timecode
from raingen.scene.timeline import ramp
scene.timeline += ramp("weather.precipitation.rate_mm_h",
                       [(0, 0.5), ("05:00", 25), ("12:00", 2)], curve="log")
rg.render(scene, minutes=12, out="storm_714.wav", layout="7.1.4", stems=True,
          captions=("srt", "edl"), start_tc="01:00:00:00", destination="post_stems")

# 6 · A thunder one-shot pack with UCS file names
rg.one_shots("thunder", count=12, out_dir="thunder_pack/")

# 7 · Variations for a sound library or a game: derived seeds, small jitter
for v in scene.variations(20):
    v.render(seconds=90, out_dir="library/")       # UCS-named files

# 8 · Real time: parameters glide, structural changes crossfade
with rg.Engine(scene, layout="binaural") as eng:
    eng.set("weather.wind.speed_mps", 14, ramp=2.0)
    eng.set("weather.thunder.distance_km", "2 km", ramp=30)
    eng.set("place.shelter", "car")
    eng.run(60)

raingen live --place "Bergen, Norway" --minutes 5 --out bergen.wav    # the weather there now
raingen play focus-steady-roof --osc 9000          # OSC control on UDP port 9000

import { WeatherEngine, defaultScene } from './engine/weather-engine.js';

const scene = defaultScene();                    // the same rainscene format the CLI renders
scene.place.shelter = 'tent';
scene.weather.thunder.enabled = true;

const engine = new WeatherEngine();
await engine.start();                            // call from a click: browsers need a gesture
engine.setScene(scene);
engine.setListener({ position: [0, 0, 0], headingDeg: 90 });

// a 12-second swell into a downpour
engine.setParam('weather.precipitation.rate_mm_h', 25, 12);

// sight and sound share one lightning channel: [x, y, z] points in metres
engine.on('flash', ({ channel, delaySec }) => console.log(`bolt of ${channel.length} points, thunder in ${delaySec.toFixed(1)} s`));
engine.on('thunder', ({ distanceKm }) => console.log(`thunder from ${distanceKm.toFixed(1)} km`));

// same graph, rendered offline to a 24-bit WAV Blob
const wav = await engine.renderOffline(90, { sampleRate: 48000 });

Install from the repository with pip install -e ".[audio]". The audio extra adds real-time playback and FLAC; osc adds OSC control. A saved storm is a rainscene JSON file of about 2 KB that the Composer, the browser engine and the CLI all read.
